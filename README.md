# Plate Solve 候选复核工作台（离线）

一个纯本机运行的 plate solving **候选比较与复核**工具。输入只是已经提取好的
**图像星点（二维像素坐标 + 亮度）** 与一份**裁剪过的本地星表（RA/Dec + 星等）**，
不做 FITS 解码，也不联网查询任何星表。求解、重放、导出全部在本机完成。

- **Node.js 后端**（内置 `node:sqlite`，无原生模块依赖）
- **Vite + TypeScript 前端**（匹配线 / 残差向量 / 被拒星点 / 参数相关性）
- **SQLite 持久化**（数据集、证据、按请求哈希幂等的求解结果）
- **可重现合成 fixture**（固定种子 PRNG，与时间/时区无关）
- **Vitest 单元 + 真实 HTTP + 临时 SQLite 的集成测试**

## 安装与启动

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm test -- --run
corepack pnpm dev -- --host 127.0.0.1 --port 5315 --strictPort
```

然后打开 <http://127.0.0.1:5315>。

重新生成合成 fixture（结果确定性，已签入仓库）：

```bash
corepack pnpm gen:fixtures
```

## 快速上手

1. 左侧“输入”可粘贴 JSON 或 CSV，或直接选择一个“合成 fixture”一键载入。
2. 设置 FOV 范围、最大旋转、是否允许镜像、畸变阶数、像素容差、失配成本与 Top-K，点“求解”。
3. 右侧查看 Top-K 候选；画布上显示匹配线、残差向量、被拒/未匹配星、锁定点与屏蔽区域。
4. 在“证据”区锁定三对对应点、屏蔽单颗星（卫星轨迹伪点）或全部饱和星，然后重新求解。
   所有判断是**只追加的新版本证据**，原始星点列表永不被改写。
5. “导出 CSV”按候选 × 匹配对导出逐点残差；“按旧规则重放”用指定规则版本与当前参数重算但不写缓存。

## 坐标约定

### 图像坐标

- 像素坐标为 **(x, y)**，原点在左上角，**x 向右为正、y 向下为正**（常见图像约定）。
- 亮度 `flux` 越大越亮；`saturated=true` 表示饱和像素（默认会被自动屏蔽）。

### 天球与切平面

- 角量一律以**度**为单位；赤经 RA ∈ [0, 360)，赤纬 Dec ∈ [−90, 90]。
- 以候选中心 **(RA0, Dec0)** 做 **gnomonic（TAN）投影**到切平面 (ξ, η)：
  - ξ 指向 **东**（RA 增大方向）；
  - η 指向 **南**（图像 y 向下的方向），即 η = −北。
- 这样图像 y-down 与非镜像天空具有**相同手性**，可直接比较行列式符号。

### 像素 → 切平面模型

阶数 `distortionOrder`：

- **0**：刚性相似（旋转 + 统一尺度 + 平移；4 对即超定）。
- **1（默认）**：一般仿射（允许 x/y 尺度与剪切），
  `ξ = a x + b y + c`，`η = d x + e y + f`。
- **2 / 3**：在仿射基础上叠加 SIP 型归一化多项式畸变
  `Σ P_ij u^i v^j`（2 ≤ i+j ≤ order），其中 `(u, v)` 是以图像中心、
  按图像半对角归一化的无量纲像素坐标。逆变换（天空→像素）对非线性项用牛顿迭代。

### 尺度、旋转与镜像（务必注意镜像约定）

- 尺度：`s = (‖(a,b)‖ + ‖(d,e)‖)/2`（弧度/像素 → 角秒/像素）。
- 行列式 `det = a e − b d`：**det < 0 即镜像（反射）候选**，在界面中单独标紫；
  非镜像旋转按 `atan2(−b, a)`、镜像按 `atan2(b, a)` 报告角度。
- 旋转角归一化到 **[0, 360)**。镜像真值在本约定下报告为
  **“镜像 + 360° − 几何角”**。例如真值为“镜像、42°”，界面显示为
  **mirror=true、rotation=318.03°**——这是同一位姿的等价表示，而非 318° 普通旋转。
  普通旋转候选与镜像候选因此永远可区分。

### RA 接缝与角度包装

- 所有跨 0/360° 的平均使用**单位向量（sin/cos）平均**，绝不对 RA 做算术平均；
  角距用点积（含接缝的短弧）计算。
- 残差 ΔRA 按 `wrap180(RA_pred − RA_cat)·cos(Dec)` 折算角秒；角度比较统一
  wrap 到 (−180, 180]。

## 求解流程（规则版本 `2025.1`）

1. **活动集**：根据证据（手动屏蔽、屏蔽多边形、饱和标记）得到活动图像星与活动星表星；
   锁定点必须引用存在的星且不被屏蔽。
2. **四边形播种**：各取最亮的一批星枚举 4 星四边形，描述子以最长边归一化、
   并加入“未归一化最长边之比”作为尺度指纹；枚举 4 种轴翻转，显式标注是否镜像。
3. **门限过滤**：由 FOV 范围与图像跨度推 rad/px 上下界，先于 LS 拟合剔除尺度不可能的对齐；
   旋转用 `min(rot, 360−rot) ≤ maxRotation` 判定（含边界）。
4. **迭代重拟合**：播种与贪心匹配阶段始终用 **order=1 仿射**（保证 4 点可解），
   双向往最近邻、一一分配并迭代；只有内点收集完成后才按用户选择的 order（0/2/3）做最终拟合。
5. **残差与代价**：
   - 像素残差 = 图像星预测切平面位置与星表切平面位置的距离，按候选 rad/px 折算为像素；
   - 角秒残差 = 预测 (RA, Dec) 与星表 (RA, Dec) 的球面角距；
   - 代价 `cost = Σ r² + mismatchCost × (未匹配图像星 + 未匹配星表星)`，
     RMS 仅作展示，**不用一个总 RMS 掩盖局部系统误差**（界面另有逐点残差表、
     放大的残差向量场和参数相关性热图）。
6. **排序与去重**：按代价升序、内点数降序、匹配集签名哈希兜底；同匹配集只保留最低代价。

### 包含规则与数值容差

- 容差边界为**闭区间（inclusive）**：`residual ≤ tolerance + 1e-9` 即内点。
  恰好落在容差上的点算匹配；残差为 0 时归一化使用 `EPSILON` 防护。
- 角度包装边界：`wrap360(360)=0`、`wrap180(±180)=+180`。
- LS 使用带列主元的高斯消元，主元相对列尺度 < `1e-12` 判奇异。

### 确定性

- 请求哈希只依赖 **规则版本 + 数据集 ID + 参数**（键名排序的稳定 JSON，SHA-256），
  不含时间戳、不依赖星点输入顺序（内部统一按 id 排序）、不依赖并行完成顺序
  （当前为确定性顺序枚举），也**不依赖本机时区**。
- 时间戳仅用于展示；fixture 由固定种子 mulberry32 生成。

## 欠定（underdetermined）语义

求解器**不会在几何不可区分时自动挑第一个候选**。以下情况标记为欠定并说明缺什么：

- 活动图像星 / 星表星少于 4，无法播种四边形；
- 锁定对应少于 3 对（二维变换需要 3 对非共线点），或锁定点共线（旋转与尺度不可分）；
- FOV / 旋转 / 镜像设置下没有任何几何一致的种子，或所有拟合奇异 / 过门限失败；
- 最优候选内点数不满足该阶数最低要求；
- Top-K 中两个候选代价差 ≤ `1e-6`（候选不可区分，建议加锁或屏蔽伪星）。

## 证据模型（只追加）

- `lock`：`{imageId, catalogId}`，需要 3 对非共线点才能驱动解；
- `mask-star`：屏蔽单颗图像星（卫星轨迹、伪星点）；
- `mask-saturated`：屏蔽所有 `saturated=true` 的星（加载时也会默认自动屏蔽）；
- `mask-region`：多边形区域（点在多边形内判定）屏蔽一串轨迹点。

证据写入后只追加不删除；原始 `imageStars/catalogStars` 保持不变。
要对比“加证据前/后”，用不同参数重新求解（产生新哈希），或新建数据集。

## 持久化与重放

SQLite（默认 `data/dev.sqlite`，Vite 开发服务内同一端口挂载 API）：

- `datasets(id, name, payload, created_at)`
- `evidence(id, dataset_id, payload, created_at)`
- `solves(request_hash PK, dataset_id, rules_version, params, result, created_at)`

重复提交同一求解请求**只返回已有结果**（响应带 `cached:true`）。
`POST /api/datasets/:id/replay` 携带 `rulesVersion` 可按**原参数 + 指定规则版本**重放，
结果不写缓存，用于老版本在新规则下的可追溯复算。

## HTTP API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/health` | 健康检查 |
| GET/POST | `/api/datasets` | 列表 / 创建（内容哈希去重，支持 JSON 或 CSV 文本） |
| GET | `/api/datasets/:id` | 数据集详情（含证据） |
| POST | `/api/datasets/:id/evidence` | 追加锁定/屏蔽证据 |
| GET/POST | `/api/datasets/:id/solves` | 求解历史 / 提交求解（幂等） |
| POST | `/api/datasets/:id/replay` | 按规则版本重放（不落库） |
| GET | `/api/solves/:hash` | 取某次求解结果 |
| GET | `/api/solves/:hash/export` | 导出逐点残差 CSV |
